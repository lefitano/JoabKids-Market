# 🛍️ Joab Kids — Loja Virtual de Roupas Infantis

> Disciplina de Desenvolvimento Web | ADS Unifor (2026)

---

## 📋 Sobre o Projeto

A **Joab Kids** é uma loja de roupas e calçados infantis que atualmente opera via Instagram e WhatsApp. Este projeto tem como objetivo digitalizar as vendas por meio de uma plataforma e-commerce completa, permitindo que clientes naveguem pelo catálogo, adicionem produtos ao carrinho e finalizem compras online.

---

## 📇 Funcionalidades

### Para o Cliente

- Cadastro e login de usuário
- Catálogo de produtos com filtragem por categorias, tamanhos e faixa etária
- Página de detalhes do produto (foto, descrição, tamanhos disponíveis)
- Carrinho de compras com cálculo do total
- Resumo e histórico de pedidos

### Para o Administrador

- CRUD de produtos (nome, categoria, preço, estoque, imagens)
- Gerenciamento de pedidos
- Gerenciamento de usuários
- Dashboard com métricas básicas
