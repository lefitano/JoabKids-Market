# Guia de Instalação e Inicialização do Projeto

Guia para configurar o projeto no PC quando clonar o repositório.


## Obrigatório instalar antes de começar

Olha se o node ta instalado na maquina.

### 1. Node.js

Para verificar se já está instalado, abra o terminal e execute:

```bash
node --version
npm --version
```

### 2. Git


### Passo 1 — Clone o repositório

No terminal, executa:

```bash
git clone https://github.com/lefitano/JoabKids-Market.git
```


### Passo 2 — Entre na pasta do projeto

```bash
cd JoabKids-Market/frontend
```


### Passo 3 — Instale as dependências

O projeto usa React e Bootstrap, que precisam ser instalados antes de rodar:

```bash
npm install
```

Avisos em amarelo não são nada, é normal.


### Passo 4 — Rode o projeto

```bash
npm run dev
```


## Encerrando o projeto

Para parar o servidor, volta no terminal e pressione:

```
Ctrl + C
```


## Resumo dos Comandos

| Etapa                | Comando                                                      |
---|
| Clonar o repositório | `git clone https://github.com/lefitano/JoabKids-Market.git` |
| Entrar na pasta      | `cd JoabKids-Market/frontend`                                |
| Instalar dependências| `npm install`                                                |
| Rodar o projeto      | `npm run dev`                                                |
| Parar o projeto      | `Ctrl + C`                                                   |
| Atualizar o projeto  | `git pull`|
